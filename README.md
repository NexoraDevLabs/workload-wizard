# Workload Wizard

Workload Wizard is an internal tool for managing academic workload allocation.  
It helps staff and administrators to plan, track, and balance teaching, simulation, and administrative hours across the organisation.

---

## 🚀 Quick Start

1. Clone the repo

   ```bash
   git clone git@github.com:ORG_NAME/workload-wizard.git
   cd workload-wizard
   ```

2. Use the correct Node + pnpm version

   ```bash
   nvm use   # or ensure Node matches `.nvmrc`
   pnpm install
   ```

3. Run the app

   ```bash
   pnpm dev
   ```

4. Run tests

   ```bash
   pnpm test
   ```
